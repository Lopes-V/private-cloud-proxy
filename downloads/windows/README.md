# Cliente Windows

[Baixar private-cloud-proxy-free-windows.zip](https://github.com/Lopes-V/proxy/raw/refs/heads/main/downloads/windows/private-cloud-proxy-free-windows.zip)

Extraia o ZIP em uma pasta gravável e execute **Start-Private-Proxy.cmd**. Informe o segredo com entrada oculta; ele não está incluído no pacote. A URL Render já vem configurada. Na primeira execução, o launcher baixa Node portátil oficial e verifica seu SHA-256.

Não exige administrador, SSH ou VPN. A execução em Windows real ainda precisa ser validada.

O checksum do ZIP está em [SHA256SUMS.txt](SHA256SUMS.txt).
